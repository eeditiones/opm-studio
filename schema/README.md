# Default schemas

The editor's autocompletion and validation for TEI, DocBook and JATS documents that name no schema of their own. Each is generated by `npm run schemas` (`scripts/schemas.py`) from the standard's own RELAX NG, twice: `<name>.json` for autocompletion with `src/runtime/completion_schema.py`, and `<name>.salve.json` for validation with salve (`scripts/salve-schemas.mjs`). Both remain under that standard's terms, not OPM Studio's AGPL.

## tei.json, tei.salve.json

Generated from `tei_all.rng` of the current TEI P5 release, <https://tei-c.org/release/xml/tei/custom/schema/relaxng/tei_all.rng>, © the TEI Consortium.
